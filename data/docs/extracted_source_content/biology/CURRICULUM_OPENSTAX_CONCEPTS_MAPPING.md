## Usage

- **curriculum_openstax_concepts_mapping.json** – Machine-readable mapping (chapters reference + `topic_to_chapters`).
- **CURRICULUM_OPENSTAX_CONCEPTS_MAPPING.md** – Human-readable reference for lesson planning.

To merge this into `biology_curriculum_structured.json`, add an `openstax_concepts_chapters` array to each topic using the `topic_to_chapters` mapping and the `chapters` object for URLs and titles.
